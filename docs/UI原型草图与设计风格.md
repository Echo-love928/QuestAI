# 《鱼皮 AI 闯关学习小程序》UI 原型草图与设计风格（待确认）

> 版本：V0.7｜日期：2026-08-26｜状态：完成首页文案收束与卡通灵感组件优化，待人工评审

> 人工确认：目标用户按 15–30 岁学生及年轻职场学习者设计；主视觉采用黄色与橙色；产品名称为“AI闯关学习”；学习搭档暂名“鱼仔”；HTML 按核心流程优先制作。

## 1. 本轮交付边界

本轮只确认视觉方向、页面结构和核心交互，不编写正式 HTML 原型。确认后再按“一个主题一个 HTML 文件、一行三列、响应式”的方式制作高保真可交互原型。

产品的首要用户任务是：

> 输入或导入想学的内容，快速生成一组题目，逐题获得反馈，最后看懂自己学会了什么。

首轮原型优先跑通：

`输入内容 → AI 生成题目 → 用户答题 → 即时讲解 → AI 复盘报告`

登录、数据库、排行、社交对战、支付等不干扰核心流程，放到扩展原型中单独呈现。

## 3. 推荐视觉方向：课桌漫画闯关簿

### 3.1 风格定义

从《阿衰》带来的“校园日常、夸张反应、手绘节奏、轻松自嘲”中提炼氛围，转译为原创视觉系统：课本纸张、黑色粗线、红笔批注、便利贴、歪斜题签和漫画拟声词。

不使用原作角色、经典服装、发型、标志、分镜或可识别画面。产品拥有自己的原创 AI 学习搭档，暂名“鱼仔”，形象方向是“一支会吐槽的机械铅笔”，避免与任何既有漫画人物相似。

关键词：`校园喜剧`、`手绘粗线`、`课桌纸张`、`反差反馈`、`聪明但不说教`。

### 3.2 设计态度

- 题目是主角，装饰不能压过可读性。
- 漫画感主要来自轮廓、批注、节奏和反馈，不靠满屏贴纸。
- 成功反馈可以夸张，普通页面保持安静。
- 失败不是惩罚，而是一次“红笔订正”。
- AI 文案短、具体、有点机灵，但不嘲讽用户。

### 3.3 唯一标志性元素

“会吐槽的红笔批注条”：每个关键页面只有一张手写批注纸条，用于解释下一步、揭示答题结果或总结薄弱点。它是整套原型最有记忆点的元素，其他装饰保持克制。

例：

- 首页：“把今天看不懂的，丢进来。”
- 生成中：“AI 正在把知识切成五小块。”
- 答对：“这题拿捏了，+10 XP。”
- 答错：“差一点，先看红笔订正。”
- 报告：“会的挺稳，不会的也抓到了。”

## 4. 视觉设计令牌

### 4.1 色彩

| 角色 | 色值 | 用法 |
| --- | --- | --- |
| 练习本纸黄 | `#FFF4C7` | 页面背景与纸张氛围 |
| 墨水黑 | `#20232B` | 正文、粗轮廓、主要按钮文字 |
| 活力橙 | `#FF8C42` | 主行动、品牌识别与关卡高光 |
| 批改红 | `#E84B3C` | 答错、重点批注，仅作为状态色 |
| 奖励黄 | `#FFD93D` | XP、金币、通关高光与大面积主氛围 |
| 订正绿 | `#33C98A` | 答对、完成、掌握知识点 |
| 白纸 | `#FFFEF8` | 题卡、输入框、报告卡片 |

规则：一个页面最多出现一个主强调色和一个状态色。批改红不是大面积背景色，避免长时间答题产生视觉疲劳。

### 4.2 字体

- 展示字：`Smiley Sans / 得意黑`，用于关卡标题、拟声词和大数字，控制在每屏 1–2 处。
- 正文字：`Noto Sans SC / 思源黑体`，用于题干、解析和报告，保证长文本阅读。
- 数字与状态：`DIN Alternate`，用于进度、XP、正确率和用时。
- HTML 原型阶段优先采用可合法分发的开源字体，并提供系统字体回退。

### 4.3 形状与层级

- 手机设计基准：`375 × 812 px`，兼容 `320–430 px` 宽度。
- 内容安全边距：左右 `20 px`；主要点击区域高度不小于 `48 px`。
- 题卡圆角：`18 px`，配 `3 px` 墨水黑轮廓。
- 主按钮：轻微不对称圆角或 1° 倾斜，按下时回正并下沉 `3 px`。
- 阴影：只用硬阴影 `4px 4px 0 #20232B`，不用通用柔光阴影。
- 正文不旋转；只有标题贴纸、拟声词和批注允许 `-2° ~ 2°` 倾斜。

### 4.4 动效

- 全套只强调一次“揭晓”：提交答案后，题卡短促压缩，结果批注从底部弹出。
- XP 增长采用数字滚动与一颗奖励星，不撒满屏彩纸。
- AI 生成采用三帧铅笔涂写循环，而不是无意义旋转器。
- 支持 `prefers-reduced-motion`，减少动效时直接切换状态。

### 4.5 第二轮视觉强化

- 内容卡片升级为半透明毛玻璃纸卡，保留粗黑轮廓与纯黑硬阴影。
- 页面背景叠加漫画网点，生成、反馈和通关节点增加克制的放射速度线。
- 答题进度条内嵌 5 个关卡节点，把数值进度和闯关地图合并成一个组件。
- 选项增加 3D 底边与按下回弹，主按钮增加低频渐变光流。
- 鱼仔采用轻微浮动，当前关卡节点和通关爆发图形采用脉冲光晕。
- 所有动效继续支持减少动效设置，桌面、平板和手机断点保持不变。
- 通关结算由单一爆炸星形升级为原创“鱼仔冠军时刻”：鱼仔居中，奖杯与终点旗分置两侧，以柔和光晕和少量纸屑组成自然的卡通叙事场景。
- 答题页采用更轻的奶油色阅读面：顶部集中展示题号、关卡路线与奖励，答案改为整行按钮，反馈、奖励和解析紧邻排列，并增加“上一题 / 继续”双操作。
- 首页开场文案收束为一句核心行动说明；空态增加可回填主题的卡通灵感卡，已输入状态增加“读取内容—生成题目—陪你闯关”卡通步骤图标。

## 5. 核心流程草图

### 5.1 首页 / 生成中 / 准备开闯

```text
┌──────────────┐  ┌──────────────┐  ┌──────────────┐
│ 鱼皮 AI  12XP│  │     生成中    │  │  RAG 入门闯关 │
│              │  │  ──────────  │  │  5题 · 约3分钟│
│ 今天想学啥？ │  │   ✎  ✎  ✎    │  │              │
│ ┌──────────┐ │  │ AI 正在把知识 │  │ ① 基础概念   │
│ │粘贴主题或│ │  │ 切成五小块…   │  │ ② 易错边界   │
│ │一段内容  │ │  │              │  │ ③ 应用判断   │
│ └──────────┘ │  │ [取消生成]    │  │              │
│ 文本 URL 文件│  │              │  │ [开始闯关！] │
│ [生成闯关]   │  │ 鱼仔批注纸条  │  │ [换一组题]   │
└──────────────┘  └──────────────┘  └──────────────┘
```

交互要点：MVP 首页默认聚焦文本输入；URL、PDF、视频以“其他导入方式”入口呈现，不抢占首要行动。生成前可设置题数和难度，但默认收起。

│ 什么是 RAG？ │  │ 什么是 RAG？ │  │ 什么是 RAG？ │
│              │  │              │  │              │
│ A. ……        │  │ A. ……        │  │ A. ……  你的  │
│ B. ……        │  │ B. ……  正确  │  │ B. ……  正解  │

│ [选好了]     │  │ │为什么？  │ │  │ │差在哪？  │ │
│              │  │ └──────────┘ │  │ └──────────┘ │
│              │  │ [下一题]     │  │ [记住了]     │

报告以“先结论、再证据、后行动”组织：正确率与一句判断 → 掌握/薄弱知识点 → 三句总结 → 复习建议。暂不设计分享海报。

## 8. 自检与取舍

初稿曾考虑“大面积彩色卡片 + 吉祥物全程陪伴”，但这会接近常见游戏化学习模板，也会挤压长题干和讲解空间。现方案改为：白纸题卡承担阅读，漫画感集中在粗线轮廓、红笔批注和一次关键揭晓动效上。

本方案刻意承担的视觉风险是“轻微歪斜的手绘结构”。控制方式是：只让标题贴纸、批注和主按钮倾斜，题干、选项、解析和数据图表始终对齐网格。

3. 产品名称使用“AI闯关学习”，原创学习搭档暂名“鱼仔”。
