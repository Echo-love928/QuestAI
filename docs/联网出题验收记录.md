## 验收结论

联网研究使用 LangChain Agent 向 DeepSeek 提供 `tavily_search` 与 `tavily_extract` 两个只读工具，由模型在受控预算内选择搜索、网页提取或组合路径。研究资料必须通过来源校验后才能进入原有题库生成流程；失败时返回明确业务错误，不会静默使用模型记忆补题。

真实联网验收已覆盖：Harness Engineering、新近 LangChain 用法、勾股定理、中英文 MCP、全球 AI Agent 安全、北京市 AI 教育政策、LangChain 官方 URL、不可直接提取 URL 的搜索恢复，以及 Mercury 同名歧义。成功题库的每道题均引用实际返回的来源 ID；同名歧义会停止出题并要求用户补充领域。

## 预算与保护

- 单次研究最多 4 次工具调用，其中搜索最多 2 次、提取最多 3 个唯一 URL。
- 搜索每次最多 8 条结果；证据正文总量最多 24,000 字符；对外题库最多保留 8 个来源。
- 研究总超时 45 秒、单工具超时 20 秒；生成接口另有登录用户/匿名客户端频率限制。
- URL 仅允许公开 HTTP(S) 地址，拒绝账号密码、localhost、环回、私网、链路本地和云元数据地址；兼容代理软件用于公网域名解析的 RFC 2544 fake-IP，直接输入该保留 IP 仍会拒绝。
- 模型伪造的来源 ID 会被剔除；没有实际来源支持的事实不能进入题库。

## 可观测性与隐私检查

研究日志只记录依据模式、工具调用顺序、搜索次数、提取 URL 数、来源数、接收/裁剪字符数、耗时和失败分类。检查确认日志不输出 Tavily/DeepSeek API Key、完整用户输入、网页正文或完整敏感 URL。

真实 Harness 记录示例：2 次搜索、12 个采集来源、24,000 个接收字符、1,013 个裁剪字符；题库按契约公开其中 8 个来源。全球主题记录示例：2 次搜索、1 次提取、2 个唯一提取 URL，最终按混合证据生成。
