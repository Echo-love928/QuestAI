## ADDED Requirements

### Requirement: 用户可选择私有或智能混合出题来源
已登录用户 SHALL 能在现有输入流程中选择 web、private 或 mixed 来源范围。private 和 mixed 请求 MUST 至少指定一个归属于当前用户且包含就绪文档的知识库；未提供新字段的旧请求 MUST 保持现有文本或 URL 出题行为。

#### Scenario: 私有资料出题
- **WHEN** 用户选择 private 并指定自己的就绪知识库
- **THEN** 系统基于检索到的私有资料创建现有异步出题任务并返回任务状态

#### Scenario: 智能混合出题
- **WHEN** 用户选择 mixed 并指定自己的就绪知识库
- **THEN** 系统必须先检索私有资料，再由 Agent 判断是否需要联网补充公开背景

#### Scenario: 未登录用户选择私有来源
- **WHEN** 匿名用户请求 private 或 mixed 来源
- **THEN** 系统拒绝请求并提示需要登录，匿名公开出题能力不受影响

#### Scenario: 旧请求保持兼容
- **WHEN** 客户端未提交 source_scope 和 knowledge_base_ids
- **THEN** 系统按照变更前的来源识别和联网研究流程处理请求

### Requirement: 私有资料题目具有可追溯引用
使用 private 或 mixed 来源生成的每道题 MUST 至少关联一个本次检索到的私有资料来源；来源 SHALL 包含稳定标识、用户可见文档名和可选页码或章节定位，不得包含本地文件路径。mixed 模式中的公开来源继续遵循现有网络证据约束。

#### Scenario: 私有题目引用文档
- **WHEN** 系统成功生成私有资料题库
- **THEN** 每道题的题干、答案和解析均可由关联的私有片段支持，且界面展示文档名称和逻辑位置

#### Scenario: 混合题目区分来源
- **WHEN** 题库同时采用私有文档和公开网页
- **THEN** 题库及历史快照明确区分 private_document 与公开网络来源

#### Scenario: 私有证据不足
- **WHEN** 所选知识库没有足够证据支持预定题量且用户选择 private
- **THEN** 任务安全失败并提示补充资料或缩小题量，不得依赖模型记忆编造内容

### Requirement: 异步出题任务保存知识库授权快照
系统 SHALL 在创建任务时校验知识库所有权和就绪状态，并保存所选知识库标识。执行任务和查询结果时 MUST 再次遵守任务所有权；删除知识库不得修改已经完成的题库及引用快照。

#### Scenario: 创建任务时知识库无权访问
- **WHEN** 请求包含不存在或不属于当前用户的知识库标识
- **THEN** 系统拒绝创建任务且不泄露目标知识库是否存在

#### Scenario: 任务执行前知识库被删除
- **WHEN** 私有出题任务尚未开始而所选知识库已被用户删除
- **THEN** 任务失败并返回可重试的资料不可用提示，不从其他来源静默出题

#### Scenario: 完成后删除知识库
- **WHEN** 用户删除曾用于已完成闯关的知识库
- **THEN** 历史详情仍保留当时的题目、答案、分析和安全引用快照
