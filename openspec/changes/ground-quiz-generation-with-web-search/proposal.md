## Why

当前题库直接基于 DeepSeek 的训练知识生成。当用户学习新概念、时效性强或存在同名歧义的主题时，模型可能使用过期资料或误判领域，例如把 “Harness Engineering” 解释成另一个领域；当用户直接提供网页时，系统也尚不能读取页面正文。出题前需要让 AI 按输入类型自主检索或提取可核验资料，并让题目严格受这些资料约束。

## What Changes

- 为文本和 URL 输入建立统一的资料获取入口：关键词或主题通过 Tavily Search 检索，合法网页 URL 通过 Tavily Extract 获取正文。
- 使用 LangChain Agent 将受控的 `tavily_search` 与 `tavily_extract` 同时提供给 DeepSeek，由 AI 根据输入、检索结果和证据充分性决定是否搜索、提取指定页面，或先搜索再提取权威结果。
- 动态调整检索深度、结果数量、内容片段数量、时间范围、语言和地域：简单知识优先摘要与低延迟检索，复杂、新颖或歧义知识增加结果并提取重要页面全文。
- 兼顾国内外资料：从用户输入推断查询语言，技术概念可补充中英文别名；全球主题不施加地域限制，地域主题使用“城市/地区写入查询词 + 国家级排序增强”。
- 在 AI 自主选择工具之外设置确定性安全边界，包括参数白名单、调用次数、URL 数量、超时、正文长度、私网地址拦截和提示注入防护。
- 将出题改为“研究 Agent 获取资料 -> 证据清洗与充分性校验 -> 基于证据结构化出题 -> 引用校验”的流程，禁止模型在证据不足时自行补全事实。
- 搜索或提取失败、无有效资料、主题存在无法消解的歧义时，不静默退回模型记忆；接口返回可识别的错误，前端保留原输入并允许重试或修改。
- 在题库响应中增加依据模式、资料获取方式和参考来源；在闯关预览与题目解析中展示来源标题、站点和可复制/打开的链接。
- 对已登录用户，将生成时的参考来源随题库快照保存，并在闯关历史详情中恢复展示；匿名用户仍可完整使用核心流程。
- 保持现有题型、答题、XP、报告和用户系统行为不变；新增输入类型和响应字段采用兼容性扩展，不移除现有 API 字段。

## Capabilities

### New Capabilities

- `grounded-quiz-generation`: 定义 AI 使用 Tavily 搜索关键词、提取网页、动态选择资料获取策略，并基于可追溯证据生成、展示和持久化题目的完整行为。

### Modified Capabilities

无。当前项目尚未建立主规格，本次以新增能力描述现有出题流程的增强契约。

## Impact

- 后端：`QuizService`、LangChain Agent/工具编排、Tavily 适配与安全校验、LLM Prompt、异常映射、题库领域模型、FastAPI 出题接口及 MySQL 题库快照持久化。
- 前端：首页启用 URL 输入、URL 校验、生成状态与错误提示、闯关预览、答题解析、历史详情、API 类型与本地存储兼容逻辑。
- 依赖与环境：新增官方 `langchain-tavily` 集成及 `TAVILY_API_KEY` 等非敏感示例配置；实施时评估并升级 LangChain 依赖，锁定与 `ChatDeepSeek` 工具调用和结构化输出兼容的版本后执行完整回归。
- 数据库：需要可重复执行的增量 SQL 保存依据模式、资料获取方式与来源 JSON；既有历史记录允许来源为空。
- 运维：Tavily Search/Extract 会增加外部依赖、延迟和费用，需要独立超时、调用预算、缓存、日志、限流和用量指标。
