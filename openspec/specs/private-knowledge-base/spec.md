# Private Knowledge Base Specification

## Purpose

让已登录用户能够安全地创建和管理相互隔离的私有知识库，把自己的 PDF、Word 和 Markdown 文档异步解析为可检索资料，并以清晰的状态、配额和错误信息控制建库全过程。

## Requirements

### Requirement: 用户管理自己的知识库
系统 SHALL 允许已登录用户创建、查看、修改和删除自己的知识库，且 MUST 拒绝访问其他用户的知识库。每位用户最多拥有 5 个知识库，名称长度为 1 至 30 个字符。

#### Scenario: 创建知识库
- **WHEN** 已登录用户提交合法名称和可选简介且未达到配额
- **THEN** 系统创建仅归属于该用户的知识库并返回其标识和统计信息

#### Scenario: 超出知识库配额
- **WHEN** 用户已经拥有 5 个知识库并再次创建
- **THEN** 系统拒绝请求并返回可识别的配额错误

#### Scenario: 跨用户访问被拒绝
- **WHEN** 用户请求查看、修改或删除不属于自己的知识库
- **THEN** 系统返回不存在或无权限响应，且不泄露目标知识库信息

#### Scenario: 删除知识库
- **WHEN** 用户确认删除自己的知识库
- **THEN** 系统删除其文档原件、向量索引和未完成索引任务，但保留已经完成的闯关历史快照

### Requirement: 用户上传受支持的私有文档
系统 SHALL 接受 PDF、DOC、DOCX 和 Markdown 文档，单文件大小 MUST 不超过 10MB，每个知识库最多保存 20 份文档。系统 MUST 拒绝加密 PDF、无法读取的文档以及扫描图片型 PDF，首版不提供 OCR。

#### Scenario: 上传有效文档
- **WHEN** 用户向自己的未满额知识库上传受支持且可解析的文档
- **THEN** 系统保存非公开原件、创建文档记录和异步索引任务，并立即返回文档状态

#### Scenario: 文件过大
- **WHEN** 上传文件超过 10MB
- **THEN** 系统在持久化和解析前拒绝文件并返回大小限制提示

#### Scenario: 文件类型不支持
- **WHEN** 用户上传不属于 PDF、DOC、DOCX 或 Markdown 的文件
- **THEN** 系统拒绝上传并返回受支持格式列表

#### Scenario: PDF 无可用文本
- **WHEN** PDF 为扫描图片、加密文件或无法提取足够文本
- **THEN** 索引任务标记为失败，原件保留，并返回不支持 OCR 或加密 PDF 的明确提示

#### Scenario: 旧版 DOC 可转换解析
- **WHEN** 用户上传可正常读取的旧版 DOC 文件
- **THEN** 系统将其转换或提取为文本后继续分块和索引

### Requirement: 文档通过异步流水线建立索引
文档 SHALL 依次经历 uploaded、parsing、chunking、embedding、ready 或 failed 状态。上传请求 MUST 不等待完整索引完成；用户 SHALL 能查询当前状态、失败原因、片段数量和更新时间，并能对失败文档发起重新索引。

#### Scenario: 查询处理进度
- **WHEN** 用户查询正在处理的文档
- **THEN** 系统返回当前阶段、可用进度信息和安全的状态说明

#### Scenario: 索引成功
- **WHEN** 文档完成解析、分块、向量化和持久化
- **THEN** 文档状态变为 ready，并记录知识片段数量及所用嵌入模型版本

#### Scenario: 索引失败可重试
- **WHEN** 文档处理因可恢复错误失败且用户发起重新索引
- **THEN** 系统清理该文档的不完整向量并创建新的处理任务，且不会影响知识库内其他就绪文档

#### Scenario: 服务重启后状态可恢复
- **WHEN** 后端在任务处理中重启
- **THEN** 数据库中的任务和文档状态仍可查询，系统能够恢复或安全地重新执行未完成任务

### Requirement: 私有知识向量按用户隔离并可删除
系统 MUST 以内部用户标识隔离向量数据，并在每个知识片段中记录知识库、文档和片段标识。检索结果 MUST 同时满足当前用户和所选知识库范围；任何用户可见响应不得包含服务器文件路径、微信 openid 或向量库内部集合名。

#### Scenario: 限定知识库检索
- **WHEN** 用户从一个或多个自己的知识库检索主题
- **THEN** 系统只返回这些知识库中状态为 ready 的文档片段

#### Scenario: 跨用户向量不可见
- **WHEN** 两个用户上传内容相同或使用相同知识库名称
- **THEN** 任一用户的检索结果都不得包含另一用户的片段或元数据

#### Scenario: 删除文档清理向量
- **WHEN** 用户删除自己的某份文档
- **THEN** 系统删除该文档原件、数据库记录和全部关联向量，其他文档保持可检索

### Requirement: 私有资料的外部传输受控
系统 MUST NOT 将私有文档原文、检索片段、服务器路径或可识别私有内容发送给 Tavily。为生成题目，系统 SHALL 只把必要的检索片段发送给已配置的 DeepSeek；界面在首次上传和混合检索时 MUST 告知用户这一数据流向。

#### Scenario: 私有模式不调用联网工具
- **WHEN** 用户选择私有资料模式生成题目
- **THEN** 系统仅检索指定知识库并调用出题模型，不调用 Tavily

#### Scenario: 混合模式保护私有内容
- **WHEN** Agent 在智能混合模式决定补充联网资料
- **THEN** Tavily 查询只包含用户主题及公开术语，不包含私有文档原文或检索片段
